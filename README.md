# movie-genre-classification-bilstm-transformer
Сравнительный анализ архитектур нейронных сетей (LSTM, Transformer, BiLSTM+Attention) для задачи классификации текстов. Проект включает полный ML-пайплайн: от оптимизированной предобработки на PyTorch до метрик качества (Accuracy 56.12%) и детального Error Analysis.
